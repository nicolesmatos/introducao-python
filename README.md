# 🐍 Exercícios e Estudos em Python

Este repositório foi criado com o objetivo de registrar a minha jornada de aprendizado, prática e consolidação de conceitos na linguagem **Python**. 

Aqui você encontrará uma coleção de exercícios práticos, scripts, pequenos projetos e experimentos desenvolvidos ao longo dos meus estudos.

---

## 🎯 Objetivos do Repositório

- **Fixação de Conceitos:** Praticar lógica de programação e sintaxe da linguagem.
- **Portfólio de Estudos:** Acompanhar minha evolução técnica ao longo do tempo.
- **Boas Práticas:** Aplicar conceitos de código limpo, organização de arquivos e documentação.

---

## 🗂️ Estrutura e Tópicos Estudados

Os exercícios estão organizados em categorias/pastas de acordo com a progressão do aprendizado:

- [x] **Fundamentos Básicos:** Variáveis, tipos de dados, operadores e entrada/saída.
- [x] **Estruturas de Controle:** Condicionais (`if`, `elif`, `else`) e laços de repetição (`for`, `while`).
- [x] **Coleções de Dados:** Listas, tuplas, dicionários e conjuntos (*sets*).
- [ ] **Funções e Módulos:** Criação de funções, parâmetros, retornos e importação de módulos padrões.
- [ ] **Tratamento de Exceções:** Manipulação de erros com `try`, `except` e `finally`.
- [ ] **Manipulação de Arquivos:** Leitura e escrita de arquivos (`.txt`, `.json`, `.csv`).
- [ ] **Orientação a Objetos (POO):** Classes, objetos, herança e encapsulamento.

## 🚀 Como Executar os Exercícios

### Pré-requisitos

Para executar os scripts, você precisará ter o **Python 3.x** instalado em sua máquina.

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/seu-usuario/nome-do-repositorio.git
   ```

2. **Acesse a pasta do projeto:**
   ```bash
   cd nome-do-repositorio
   ```

3. **Execute um arquivo especificado:**
   ```bash
   python3 caminho/do/exercicio.py
   ```
   *(Ou utilize `python caminho/do/exercicio.py` dependendo do seu sistema operacional)*
